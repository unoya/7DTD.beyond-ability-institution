這些模組是A17版本時期寫的, 當時官方並沒有中文化語系檔可以使用, 所以道具都沒有中文可以看.
因為年代久遠, 我只能依照當時的目錄建立日期來推斷模組建立的順序:

- SpeedSmelting  
加快熔爐的冶煉速度, 並延長木頭可燃燒時間.
- CraftMyItem  
定制自己想要的道具配方.
只針對扳手、酸化物、小引擎、電池、太陽能電池、燒杯、沖模工具、抽血器、橄欖球帽、太陽能發電機.
- CrossbowMagazineUp  
客製化一把十字弓專用的彈匣模組, 有3發、5發、10發三種模組可替換.
模組藍圖在野外撿垃圾有機率出現, 商人也有機率會販售.
- LetMeEasy  
為了降低生存的難度.
  - 玩家新開地圖後, 剛進地圖會送禮包.
  - 調整玩家跳躍能力與游泳消耗的耐力值.
  - 更改一些道具的冶煉時間.
  - 延長木頭的燃燒時間.
  - 增加玩家空手攻擊的速度與耐力.
  - 提升一些近戰武器和遠程武器的基礎數值.
  - 提升交通工具的耐久值、加速度、扭力.
  - 提升礦工帽與書呆子眼鏡的基礎值, 並追加特定效果.
  - 提升刀片陷阱與感電柵欄的基礎數值、降低電力需求.
  - 提升自動砲塔的射擊次數、最大射程、降低電力需求.
  - 降低某些電力設備的電力需求.
  - 減少某些方塊升級所需材料量.
  - 提升強化水泥塊與鋼板塊的最大耐久值與防爆性能.
  - 降低鑽孔機與電鋸的噪音值, 降低吸引貞子的因素.
  - 調整各區域野生動物的最大生成數量.
  - 調整商人的開業時間、販賣商品的數量, 並更改世界各地販賣機可收購玩家所販賣的東西.
- HardBuilding  
  - 增加自訂的方塊「鐵絲網與欄杆」, 並可在熔爐進行製作.
- StrongLaborHelmet  
  - 增加自訂的頭盔「強力勞工頭盔」, 穿戴後可提升玩家各種能力.
  - 該頭盔可在工作台製作, 商人也有機率會販售.
- CheapTurret  
  - 增加一個自訂砲塔, 可使用任何道具作為子彈, 但是射程遠、基礎傷害低、容易修復.
- TitaniumEquipment  
  - 增加四個模組「重型鈦護甲」、「輕型鈦護甲」、「天使之吻」、「一拳的奧義」.
  - 護具的藍圖在野外有機率搜到.
  - 工具「鈦大錘」可在工作台自行製作.

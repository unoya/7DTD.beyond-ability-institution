# 此版本的功能如下
- 野外的中型鵝卵石會掉落銅素材.
- 增加自訂的「強化型刀片陷阱」、「強化型電擊柵欄」、「強化型鐵絲網」、「強化型木釘」、「強化型有刺鐵線」、「強化型有刺鐵絲柵欄」、「強化型木刺柵欄」、「強化型鐵刺柵欄」、「強化型飛鏢陷阱」、「電擊型感應板」、「焰燒型感應板」、「強化型輪轂地雷」、「電擊型輪轂地雷」、「焰燒型輪轂地雷」、「毒爆型輪轂地雷」、「強化型雷管炸彈」、「強化型汽油彈」.
- 增加自訂的元素子彈「燃燒彈」、「電擊彈」、「放血彈」、「麻醉彈」、「熔鋼彈」、「聖光彈」、「霜咬彈」.
- 增加自訂的元素石頭炸彈, 一顆平凡的石頭, 丟出去碰撞後會立即爆炸.
- 增加自訂的近戰武器「不滅火把」、「藍波刀」、「詛咒刀」.
- 增加自訂的模組藍圖「火焰彈模組」、「電擊彈模組」、「放血彈模組」、「麻醉彈模組」、「熔鋼彈模組」、「聖光彈模組」、「霜咬彈模組」、「高彈匣模組」、「長射槍管模組」、「崩分離析模組」.
- 增加自訂的特殊藥水, 搭配自訂技能運作.
- 增加自訂的殭屍「火焰型殭屍」、「閃電型殭屍」、「猛毒型殭屍」、「麻醉型殭屍」、「勾魂型殭屍」、「冰凍型殭屍」以及特殊型的殭屍BOSS.
- 增加自訂的任務, 約30個左右.
- 增加自訂的技能.
  - 元素型傷害技能

    - 增強麻醉時間
    - 提升熔鋼機率
    - 增強聖光傷害, 學習額外技能可造成擴散效果
    - 增強霜咬傷害與時間, 學習額外技能可造成擴散效果
  - 元素型製作技術
    - 習得元素子彈的製作方法
    - 習得元素模組的製作方法
    - 習得元素引爆物的製作方法
  - 強化型製作技術
    - 習得強化型陷阱的製作方法
    - 習得強化型槍械模組的製作方法
    - 習得強化型藥品的製作方法

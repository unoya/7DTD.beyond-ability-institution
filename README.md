# 超能機構 (Beyond Ability Institution)

目前版本：18.4

- BEABIN
  - 主模組，一定要安裝。

- BedRecoveryHealth
  - 附加模組，可選擇性安裝。
  - 用途：當玩家站在床上時，會逐漸回復生命力與耐力。

- DropOtherMinerals
  - 附加模組，可選擇性安裝。
  - 用途：挖掘礦脈時，有機率性額外掉出銅礦。

- HighestLevel
  - 附加模組，可選擇性安裝。
  - 用途：提升玩家等級上限至999級。

- PickUpBlocks
  - 附加模組，可選擇性安裝。
  - 用途：修改某些方塊可以被玩家撿起來帶回家。

- ItemStack
  - 附加模組，可選擇性安裝。
  - 用途：道具堆疊量３萬。
